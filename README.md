# 🛡️ Linux安全防控系统 (Linux Security Defense System)

## 项目简介
专业的开箱即用Linux平台安全防控系统，基于Web的现代化安全管理仪表盘。

## ✨ 核心功能

### 🔐 十大安全模块
1. **📊 安全仪表盘** - 实时系统状态监控与安全评分
2. **🔥 防火墙管理** - iptables规则可视化配置与管理
3. **👥 用户权限管理** - 用户账户、sudo权限、SSH密钥管理
4. **⚙️ 服务监控** - 系统服务状态实时监控与控制
5. **📝 日志审计** - 系统/认证/安全日志集中查看与分析
6. **🚨 入侵检测** - 实时威胁检测与告警通知
7. **🔍 漏洞扫描** - 系统漏洞自动扫描与修复建议
8. **🌐 网络监控** - 网络连接、带宽、端口实时监控
9. **💾 备份恢复** - 自动化备份策略与一键恢复
10. **⚙️ 安全设置** - 密码策略、SSH加固、系统加固配置

### 🎯 技术特性
- **纯前端实现**: 无需后端服务器，直接浏览器打开即可使用
- **响应式设计**: 完美适配桌面端和移动设备
- **现代化UI**: 深色主题，专业级视觉设计
- **交互丰富**: 实时数据模拟、动态图表、操作反馈
- **开箱即用**: 零配置启动，即开即用

## 📦 快速开始

### 方式一：直接使用（推荐）
1. 下载或克隆本项目
2. 用浏览器打开 `index.html` 文件
3. 开始使用！

```bash
# 克隆项目
git clone git@github.com:Paoulo31/1.git
cd 1

# 直接打开
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

### 方式二：本地HTTP服务
```bash
# Python 3
python3 -m http.server 8000

# Node.js
npx serve .

# 访问 http://localhost:8000
```
